Protocol Snapshot API

Read published Olympus protocol snapshots and contract ABIs. Data routes serve the active accepted snapshot, which can lag the live chain.

Explore the API

  • OpenAPI specification — request paths and response schemas.
  • Published chains — available chain IDs and snapshot paths.
  • Ethereum protocol snapshot — example of /v1/chains/{chainId}/protocol.
  • Active manifest — public snapshot metadata.
  • Indexing bounds — snapshot generation time and indexing progress.
  • Contract ABI registry — ABI lookup by chain, address or label.

Routes accept GET and HEAD without request bodies or query parameters. OPTIONS provides CORS metadata.

Service status

  • Liveness — the gateway process is running.
  • Readiness — required snapshot artifacts and the ABI registry are available.
